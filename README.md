## 📈 Ключевые навыки и компетенции
* **Продуктовая аналитика:** Расчет и мониторинг метрик (DAU/MAU, Retention Rate, Churn Rate, LTV, CAC, ROI).
* **Статистический анализ:** Проектирование, проведение и оценка результатов A/B и A/A-тестирования (параметрические и непараметрические критерии, фильтрация выбросов).
* **Базы данных:** Написание сложных SQL-запросов (Оконные функции, СTE, подзапросы, оптимизация JOIN-ов).

* **Сбор и анализ требований:** Анализ бизнес-требований, декомпозиция задач, написание ФТ/ТЗ, проектирование Use Cases и User Stories.
* **Моделирование процессов (UML / BPMN):** Проектирование диаграмм процессов в BPMN 2.0 (AS-IS/TO-BE) и системной архитектуры в UML (Sequence, Use Case, Activity) с использованием Draw.io и Miro.
* **Проектирование API и интеграций:** Разработка спецификаций для интеграционных решений (REST API, SOAP), проектирование структуры JSON/XML, тестирование запросов в Postman.
* **Работа с СУБД и данными:** Проектирование ER-диаграмм, написание SQL-запросов (PostgreSQL, Oracle) для проверки структур данных и выгрузки аналитики.
* **Инструментарий:** Jira, Confluence, Git, Postman, Camunda, VS Code.
